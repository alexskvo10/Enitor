# Environment setup

## 1. Flutter SDK

1. Download the stable ZIP release: https://docs.flutter.dev/get-started/install/windows
2. Extract it, e.g. to `C:\src\flutter` (important: NOT under `Program Files` — write access is required)
3. Add `C:\src\flutter\bin` to the `PATH` environment variable
4. Restart PowerShell and check:
   ```powershell
   flutter --version
   ```

## 2. Dependencies

```powershell
flutter doctor
```

This command shows what's missing. You'll most likely need:

### Android
- **Android Studio**: https://developer.android.com/studio
- Install Android SDK + Platform Tools + an emulator (via SDK Manager)
- Accept the licenses:
  ```powershell
  flutter doctor --android-licenses
  ```

### Windows (desktop)
- **Visual Studio 2022 Build Tools** with the *Desktop development with C++* component:
  https://visualstudio.microsoft.com/downloads/

## 3. Install project dependencies

From the repository root:
```powershell
flutter pub get
```

## 4. Run

```powershell
flutter devices                 # list available devices
flutter run -d windows          # Windows desktop
flutter run -d emulator-5554    # Android emulator/device (id from flutter devices)
```

Hot reload — press `r` in the terminal running `flutter run`.

> The repository contains a `web/` folder (generated by `flutter create`), but
> web is not a supported platform for this project: it's not tested and not
> included in releases.

## 5. Building a release

```powershell
flutter build windows --release           # → build\windows\runner\Release\
flutter build apk --release               # → build\app\outputs\flutter-apk\app-release.apk
```

A signed Android release requires `android/key.properties` + a keystore
(neither is in the repository — see `.gitignore`); without them, a
debug-signed APK is built instead.
